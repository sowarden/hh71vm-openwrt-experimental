# Из чего собран образ и где взять исходники

Образ содержит код под лицензией **GPL-2.0**, поэтому происхождение всех частей описано
здесь явно.

## Состав

| Компонент | Версия / происхождение | Лицензия |
|---|---|---|
| OpenWrt | ветка 19.07 | GPL-2.0 |
| Ядро Linux | 4.14.275 (из состава OpenWrt) | GPL-2.0 |
| BSP для SoC RTL8197F | вендорский Realtek SDK, форвард-порт с ядра 4.4 на 4.14 | GPL-2.0 |
| Ethernet/switch-драйвер (`rtl819x`) | вендорский Realtek SDK v3.6.0 | GPL-2.0 |
| Wi-Fi-драйвер (`rtl8192cd`) | вендорский Realtek SDK v3.4.14b | GPL-2.0 |
| `iwpriv` | wireless_tools 29 из вендорского SDK | GPL-2.0 |

Вендорские исходники Realtek взяты из **открыто опубликованных GPL-архивов** производителей
устройств на том же семействе чипов: архив D-Link DIR-842E (SDK v3.4.14b, откуда взят
Wi-Fi-драйвер) и архив TP-Link Archer AX12 (SDK v3.6.0, откуда взяты BSP и Ethernet-драйвер).
Эти архивы производители обязаны публиковать по условиям той же GPL-2.0.

## Что было изменено

Сборка — это чистое дерево OpenWrt 19.07 плюс дельта:

- новый таргет `rtkmipsel/rtl8197f` (описание платы, конфигурация ядра, сборка образа);
- пять патчей к ядру: подключение архитектуры, раскладка регистров UART, подключение
  Ethernet- и Wi-Fi-драйверов, экспорт двух символов работы с кэшем DMA;
- вендорские драйверы, разложенные оверлеем, с правками под ядро 4.14 и компилятор GCC 7.5
  (в основном приведение типов, недостающие объявления и исправление нескольких выходов за
  границы массивов, которые нашёл компилятор).

## Исходные тексты

Полная дельта сборки (всё, что перечислено выше) публикуется отдельно. Если вам нужны
исходники прямо сейчас, а репозитория с ними ещё нет — откройте issue, и они будут
предоставлены.

Само дерево OpenWrt не форкалось: берётся ветка 19.07 из официального репозитория, поверх
накладывается дельта.

## Прошивка радиочипа

В образе присутствуют бинарные прошивки радиочастей (`rtl8197Ffw`), входящие в состав
вендорских GPL-архивов в виде данных. Их лицензионный статус определяется условиями
производителя чипа; они не изменялись и включены в том виде, в каком поставляются вендором.
